# Code of conduct

## Our standard

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, and keep discussion focused on the
work. Harassment, personal attacks, and demeaning comments are not acceptable in
issues, pull requests, reviews, or any other project space.

Security research is welcome and expected here. Reporting a flaw in this project
is a contribution, not an attack — see [SECURITY.md](SECURITY.md) for how to do it
privately.

## Reporting

Report unacceptable behaviour to a maintainer listed in `GOVERNANCE.md`. Reports
are handled privately. Maintainers who do not follow this code in good faith may
be removed from the project.
